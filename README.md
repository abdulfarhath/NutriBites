Nutrition Tracker

A Nutrition Tracker web application built using React that helps users monitor their calorie intake, calculate BMI, and maintain a healthy diet plan. Users can add food, track meals, and interact with an AI-powered FoodBot for nutrition guidance.

Features

User Authentication: Login and Signup functionality.

Profile Management: View and update user details such as age, weight, height, and gender.

BMI Calculation: Automatically calculates BMI and determines health status.

Calorie Tracking: Calculates and suggests daily calorie intake based on user metrics.

Food Logging: Add food items to track daily consumption.

AI-Powered FoodBot: Get nutrition advice and food recommendations.

Meal Planning: Plan meals based on dietary requirements.

Tech Stack

Frontend: React, React Router, TailwindCSS

Icons: React Icons

State Management: useState, useEffect
